从你正在做的事，

一项作品、一个具体问题，或是一段值得分享的经历，都可以成为我们认识彼此的起点。

给创造者

带着你的实践来。

你可以先告诉我们：

  • 最近主要在做什么，具体负责哪一部分？
  • 有没有一项可以查看或体验的作品？
  • 想获得什么反馈，或者寻找什么伙伴？

还没有成熟作品，也可以从一份个人介绍和一个真实问题开始。

给产品团队

带着一个真实问题来。

可以一起讨论：

  • 产品体验与校园使用场景探索
  • 创作者内容、案例与活动共创
  • 有明确目标、成员分工与成果的实践项目

合作前共同确认交付、时间、预算、成员报酬与成果使用方式。
