# MoonSpace 个人说明书工坊

公开入口：https://moonspace-ai.github.io/intro/

纯静态浏览器工具，无登录、数据库或外部 AI 服务。填写数据仅存于当前浏览器的 localStorage；本地存储不可用时页面会提示下载备份。公开部署代码和资源不包含用户草稿。

- 六组填写提示与即时预览。
- JSON 草稿备份和恢复；清空、替换已有草稿前确认。
- Markdown 导出、复制与可离线打开的独立 HTML 导出。
- 伙伴见证需注明见证人并勾选已获确认后才随说明书导出；不产生平台认证。
- 不自动发布个人卡片或生成公开卡片链接。公开页面可经成员确认后，由社区维护者发布。

HTML 导出会读取同目录的 studio.css 并内联，移除字体网络依赖。工具自身字体为 ZCOOL KuaiLe 子集，许可见 ../assets/FONT-LICENSE.txt。

测试辅助：studio.js 在 Node 中导出纯函数，可测试数据恢复、链接校验、输出转义和见证导出逻辑。
