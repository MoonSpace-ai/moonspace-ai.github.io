成为一个有历史的人

把做过的事情、当时的条件和踩过的坑留下，让后来的人有机会少摸索一些。

一个人真正留下的历史，可以是一次选择、一份作品，也可以是一次没有做对的尝试。它们让别人有机会理解：你是怎样走到这里的。

把当时的处境一起留下

同一个建议，放到不同的人身上，可能会得到完全不同的结果。记录经历时，除了结果，也值得写清楚当时有什么、想要什么、受到什么限制，以及为什么做出那个选择。

经验提供线索，判断仍属于读者

一个人的通关记录，可以给后来的人多一点信息，但不必成为所有人的标准答案。把条件、尝试和反思放在一起，读者才能判断哪些适合自己。

从一件具体的事开始

不必等到经历足够精彩。可以先写一个最近完成的项目：遇到了什么问题，试过什么方法，结果如何，下次准备怎样调整。
