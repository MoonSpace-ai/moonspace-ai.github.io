公开学习

让做事的过程，被彼此看见

一份正在更新的记录，可以成为反馈、陪伴与下一次合作的入口。

公开学习，不一定要面对很多陌生人。一个朋友、一个同伴，或者一小群期待你下一次更新的人，也可以构成你的 public。

把模糊的目标，变成可以回应的进展

告诉别人你正在做什么、卡在哪里、下一步准备试什么，比笼统地宣布一个大目标，更容易收到具体反馈。

过程本身也有价值

新手记得自己刚刚在哪里卡住。这些即时的经验，可能恰好帮助另一位正在经历同样问题的人。记录不必等到最终成果完成之后才开始。

给下一次交流留一个话头

有持续记录，彼此就能从上一次的进展继续聊起。慢慢地，旁观、反馈和共同尝试也有机会变成真实协作。
