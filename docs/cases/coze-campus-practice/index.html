从新生的一个问题，找到 AI 的校园用法。

Coze 校园应用实践

从什么问题出发

校园里的 AI 使用不只有搜题。如何从学生身边的真实问题出发，找到更具体的产品价值，是这次实践关注的问题。

我们参与的部分

  • 围绕新生入学时反复出现的问题，整理校园知识与答疑场景。
  • 使用 Coze 制作知识库问答助手，形成能够体验的应用。
  • 记录实现方式与使用经验，为其他院校成员开展校园实践提供参考。

留下的成果

  • 面向校园答疑的 Agent 学业助手
  • 应用场景与最佳实践记录
  • 供其他院校成员参考的实践方法

从这次实践继续

先找到一个愿意反复被解决的问题，再讨论工具能力。一个具体场景，也可以成为产品与校园建立持续连接的起点。
