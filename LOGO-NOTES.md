# 透明底 Logo

最终资产：`dist/assets/moonspace-logo.png`。

工具：内置 imagegen 编辑模式，透明背景开启。源图来自用户指定的 MoonSpace GitHub 仓库 `logo.jpg`。输出为 RGBA PNG，已检查存在透明与不透明像素；网站保留原有蓝、绿、橙配色，使用 CSS 调整标志展示区域。

最终提示词：

> Use case: background-extraction. Edit target: the provided MoonSpace.ai official logo. Remove all white background and make it truly transparent, including the white negative spaces inside the mark. Preserve the exact existing navy blue, green and orange interwoven crescent mark: its geometry, stroke width, colors, proportions and clean edges must remain unchanged. Preserve the exact existing MoonSpace.ai lettering below it, unchanged. No new design, no extra shapes, no shadows, no glow, no embellishment. Keep the complete logo and wordmark centered, tightly but comfortably framed. Output one crisp transparent PNG suitable for a website header and hero.
